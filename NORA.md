# 🤖 NORA

**N**eural **O**rchestration & **R**esearch **A**ssistant

---

## What is NORA?

NORA is an intelligent AI system that builds applications for you. You just describe what you want in plain English, and NORA handles everything:

- ✓ Understanding your requirement
- ✓ Planning the architecture  
- ✓ Choosing the best frameworks and libraries
- ✓ Researching documentation automatically
- ✓ Installing all dependencies
- ✓ Writing complete, working code
- ✓ Creating tests
- ✓ Reviewing the code for quality

---

## How to Use NORA

### 1. Start NORA
```bash
./run.sh
```

### 2. Describe What You Want
```bash
nora> goal Create me an application for budget tracking
```

### 3. NORA Builds It!
That's it. NORA figures out everything else and delivers a working application.

## Key Features

### 8 Specialized Agents
- **Orchestrator** - Manages the workflow
- **Planner** - Creates the project plan
- **Coder** - Writes the code
- **Reviewer** - Reviews code quality
- **Research** - Researches frameworks
- **Tester** - Creates tests
- **Memory** - Stores knowledge
- **Installer** - Installs dependencies

### 3-Layer Memory System
- Short-term: Current session
- Long-term: Persistent storage
- Vector: Semantic search

### Smart Framework Management
- Auto-detects what frameworks are needed
- Researches them automatically
- Installs with confirmation
- Uses them correctly
